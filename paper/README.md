# Paper tables

`tables/` holds the tables that appear in the paper, each as `.tex` (what the
paper `\input`s), `.md` and `.csv`. They are generated by
`scripts/make_tables.py` from the files in `results/`, never edited by hand;
`scripts/reproduce_analysis.sh` rebuilds them and `git status` shows whether
anything changed.

| file | paper |
|---|---|
| `tab-main-results` | Table 1 |
| `tab-ablation` | Table 2 |
| `tab-systems` | Table 3 |
| `tab-router` | Table 8 |
| `tab-router-stats` (`-full.csv` has every family and correction) | Table 9 |

Tables 4–7 are typeset in the paper from `results/analysis/*.json`; the README
maps each one to its file.
